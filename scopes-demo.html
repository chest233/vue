Chrome DevTools [[Scopes]] 作用域类型演示

📝 说明

在 Chrome 浏览器控制台中，函数的 [[Scopes]] 属性显示了该函数可以访问的所有作用域。

主要的作用域类型包括：Script、Block、Closure、Local 和 Global。

请按 F12 打开开发者工具，然后点击下面的按钮来查看不同的作用域示例。

1. Script 作用域

Script 作用域包含在模块或脚本文件顶层使用 let/const 声明的变量。

2. Block 作用域

Block 作用域由花括号 {} 创建，配合 let/const 使用。

3. Closure 闭包作用域

当内部函数引用外部函数的变量时，会创建闭包作用域。

4. 综合示例

这个示例展示了多个作用域类型如何嵌套。

5. 实用技巧

查看函数作用域的方法：

  1. 使用 console.dir(函数名) 查看函数对象，展开 [[Scopes]] 属性
  2. 在函数中设置 debugger 断点，在 Sources 面板查看 Scope 窗格
  3. 使用 Chrome DevTools 的 "Pause on exceptions" 功能
